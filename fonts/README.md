# Extra fonts

Drop `.ttf`, `.otf` or `.ttc` files here (for example a brand font your decks use) and the
app installs them on startup, so slides render with the right text widths and line breaks.
Only add fonts you're licensed to use, and keep in mind that a public repo makes them public.

Microsoft's common fonts (Arial, Trebuchet MS, Verdana, Georgia, Times New Roman, Courier New,
Comic Sans, Impact) are downloaded automatically and don't need to go here.
Reboot the app after adding fonts.
