# Deck library

Put `.pptx` files here. Subfolders are fine (e.g. `decks/Clients/Acme/`); each folder
shows up in the app's **Folder** picker and its files in the **File** picker.

To add files on github.com: open this folder → **Add file → Upload files**.
To create a subfolder, use **Add file → Create new file** and type `NewFolder/README.md`
as the name (GitHub has no empty folders).

Streamlit Cloud redeploys automatically after each commit, so new files appear in the app
within a minute or so.
